# Diretrizes de Uso do Logotipo SINARCA

### 1. Versões
*   **Colorida**: Para fundos brancos ou claros.
*   **Monocromática Escura**: Para impressões P&B ou fundos neutros.
*   **Monocromática Branca**: Para fundos escuros ou verdes.

### 2. Aplicações em Interfaces Digitais
*   **Header**: 60-80px de largura, canto superior esquerdo.
*   **Footer**: 40-50px, monocromático branco.
*   **Favicon**: Versão simplificada 32x32px.

### 3. Estados de UI
*   **Botão Primário**: #1B5E20 (Verde Floresta).
*   **Hover**: #0D3817.
*   **Botão Secundário**: #81C784 (Verde Tecnologia).

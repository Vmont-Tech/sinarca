# SINARCA: Sistema Nacional de Rastreabilidade de Créditos Ambientais
## Guia Definitivo de Documentação Técnica

Este repositório contém a documentação completa para o projeto SINARCA, servindo como a "bíblia" técnica para orientar a equipe de desenvolvimento na construção da plataforma. O SINARCA é uma infraestrutura de soberania ambiental que utiliza tecnologias de ponta para garantir a rastreabilidade, transparência e segurança no mercado de créditos de carbono.

### Tecnologias Chave

*   **Hardware:** Tags NFC 424 DNA (QTAGs) para identificação física inviolável.
*   **Satélite:** Sentinel-2 (Copernicus) para monitoramento ambiental contínuo.
*   **Blockchain:** Blockchain e Smart Contracts para tokenização e registro imutável de créditos.
*   **IA:** Algoritmos próprios para cálculo de NDVI e detecção automática de anomalias.
*   **Segurança:** Criptografia Pós-Quântica (NIST PQC-2024) e autenticação biométrica/geolocalizada.

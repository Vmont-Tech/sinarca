# SINARCA: Sistema Nacional de Rastreabilidade de Créditos Ambientais

## Guia Definitivo de Documentação

Este repositório contém a documentação completa para o projeto SINARCA. O SINARCA é uma infraestrutura de soberania ambiental que utiliza tecnologias de ponta para garantir rastreabilidade e segurança no mercado de créditos de carbono.

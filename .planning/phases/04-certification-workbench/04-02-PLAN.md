<objective>
Montar o dossiê técnico da certificadora no backend e fechar o vazamento de dados internos no dossiê público.

Purpose: CERT-01 exige que a certificadora abra revisão detalhada com baseline, documentos, QTAGs e cálculo de potencial — hoje não existe endpoint que entregue isso de uma vez. CERT-05 e D-20/D-22 exigem que o público veja só decisões finais e o certificado; hoje `/projects/{id}/public-dossier` (rota SEM autenticação) devolve `notes` de toda certificação e TODOS os documentos do projeto, incluindo matrícula e inventário florestal. Esse vazamento é pré-existente e é um defeito de segurança (ASVS V8), não apenas de UX.
Output: Helpers de dossiê mínimo e cálculo em `ProjectsService`, serializadores públicos separados dos internos, e o endpoint `GET /api/v1/certifier/projects/{id}/review`.
</objective>

```python
    async def certification_dossier_status(self, project: Project) -> dict[str, Any]:
        """Estado do dossiê mínimo exigido pela D-03 antes de qualquer decisão."""
```
Comportamento exato:
- Carrega o baseline mais recente: `select(ProjectBaseline).where(ProjectBaseline.project_id == project.id).order_by(ProjectBaseline.captured_at.desc()).limit(1)`.
- Carrega tags: `select(ProjectTag).where(ProjectTag.project_id == project.id).order_by(ProjectTag.vertex_label)`.
- Tag válida = `tag.status.upper() == "ACTIVE"` e `tag.latitude is not None` e `tag.longitude is not None`.
- Carrega documentos: `select(Document).where(Document.project_id == project.id)`; `present_types = {d.document_type.upper() for d in documents}`.
- Para cada grupo em `REQUIRED_CERTIFICATION_DOCUMENT_GROUPS`, o grupo está satisfeito se `set(group_types) & present_types` não é vazio.
- Retorna:
```python
{
    "complete": bool,
    "missing": list[str],           # rótulos PT-BR: "baseline", "quatro QTAGs/geofence válidas", "documentos obrigatórios"
    "baseline": {"present": bool, "capturedAt": str | None, "sentinelSceneId": str | None},
    "tags": {"total": int, "valid": int, "required": 4, "complete": bool},
    "documents": {
        "presentTypes": sorted(present_types),
        "missingGroups": ["documento legal ou CAR", ...],
        "complete": bool,
    },
}
```

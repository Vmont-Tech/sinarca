- Cobre Checklist 1:
  - Dossiê público do projeto com histórico, QTAGs, baseline, certificação, auditoria, créditos e transações.
  - Explorer de transações com filtros por projeto, hash, tipo, comprador e status.
  - Perfis públicos de certificadoras, auditores, empresas e produtores com dados do banco.
- Cobre Checklist 2:
  - Base de dados/API para perfil público e edição de perfil posterior.
- Fora de escopo:
  - Renderização completa das telas fica nos planos `02-03` e `02-04`.
  - Provisionamento admin fica na Phase 9.
  - Governança avançada de privacidade fica na Phase 10.
- Gate de dados:
  - Todo dado demonstrativo necessário deve estar em `supabase/seed.sql`.
  - API não pode montar respostas a partir de mocks runtime.
- UAT obrigatório:
  - Validar payloads reais em ambiente local via chamadas HTTP antes de liberar a UI.
</coverage>

<threat_model>
## Threat Model

- **Ameaça:** expor dados pessoais sensíveis em endpoints públicos.
  **Mitigação:** DTO público com campos minimizados, documento mascarado ou status verificado quando aplicável.
- **Ameaça:** UI depender de múltiplas chamadas frágeis para montar dossiê.
  **Mitigação:** criar resposta agregada para detalhe público ou endpoints específicos documentados.
- **Ameaça:** filtros de transação divergirem entre API e frontend.
  **Mitigação:** testes de contrato com query params e casos seedados.
- **Ameaça:** seed insuficiente levar frontend a criar fallback hardcoded.
  **Mitigação:** completar seed antes da UI e testar payloads.
</threat_model>

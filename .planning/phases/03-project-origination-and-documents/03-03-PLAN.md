<objective>
Adicionar uma camada de captura de campo web/PWA que detecta suporte a NFC/geolocalização, falha fechado quando o ambiente não permite validação real, e exibe preview de geofence derivado das quatro QTAGs.
</objective>

- `src/pages/Dashboard/AddProject.tsx`
- `src/services/projectOrigination.ts`
</context>

<coverage>
## Cobertura do checklist

- Cobre Checklist 3:
  - cliente de campo web/PWA/mobile quando ambiente permitir;
  - captura/fallback de coordenadas;
  - geofence real calculado a partir de `project_tags`;
  - bloqueio explícito para SUN/CMAC/hardware.
- Fora de escopo:
  - app nativo NFC completo;
  - validação criptográfica real com chave mestra/HSM;
  - integração Sentinel live.
- Gate de dados:
  - preview usa tags preenchidas pelo usuário e depois persistidas via `/api/v1/projects`.
- UAT obrigatório:
  - testar caminho sem NFC e caminho com geolocalização negada.
</coverage>

<threat_model>
## Threat Model

- **Ameaça:** Web NFC indisponível ser apresentado como validação real.
  **Mitigação:** status `unsupported`/`manual` visível e copy explícita.
- **Ameaça:** geolocalização negada bloquear todo fluxo sem alternativa.
  **Mitigação:** fallback manual com aviso auditável.
- **Ameaça:** geofence visual não corresponder aos pontos enviados.
  **Mitigação:** componente recebe exatamente a lista de tags normalizadas.
</threat_model>

<tasks>
<task id="T1" type="execute">
  <title>Criar adapter de capacidade de campo</title>
  <read_first>
    - `.planning/phases/03-project-origination-and-documents/03-RESEARCH.md`
    - `src/services/projectOrigination.ts`
  </read_first>
  <action>
    Criar `src/services/fieldCapture.ts` exportando:
    - `type FieldCapability = { nfc: 'available' | 'unsupported'; geolocation: 'available' | 'unsupported'; secureContext: boolean }`;
    - `detectFieldCapabilities(): FieldCapability`;
    - `requestCurrentPosition(): Promise<{ latitude: number; longitude: number; accuracy?: number }>`;
    - `type NfcCaptureStatus = 'unsupported' | 'blocked_missing_credentials' | 'manual_entry_required'`;
    - `getNfcCaptureStatus(): NfcCaptureStatus`.

    `detectFieldCapabilities()` deve checar:
    - `window.isSecureContext`;
    - `'NDEFReader' in window`;
    - `'geolocation' in navigator`.

    `getNfcCaptureStatus()` deve retornar `blocked_missing_credentials` quando `NDEFReader` existir, porque a fase não tem chave SUN/CMAC/KMS real; retornar `unsupported` quando não existir.
  </action>
  <verify>
    `rg -n "NDEFReader|isSecureContext|geolocation|blocked_missing_credentials" src/services/fieldCapture.ts && npm run build`
  </verify>
  <acceptance_criteria>
    - O arquivo compila sem dependências novas.
    - Não há chamada que prometa validação SUN real.
    - Geolocalização retorna Promise com lat/lng numéricos ou erro controlável.
  </acceptance_criteria>
</task>

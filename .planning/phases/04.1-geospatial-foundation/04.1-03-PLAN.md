<objective>
Detect geometric overlap between two SINARCA projects and quantify it: a `ProjectsService.detect_boundary_overlaps()` method that uses `ST_Intersects` as the index-backed pre-filter and `ST_Area(ST_Intersection(...)::geography)` for the actual numbers, plus a thin authenticated endpoint so the behaviour can be exercised end-to-end over HTTP rather than only from a Python test reaching into the service layer.

Purpose: GEOF-04. This is the foundational signal that Phase 04.2's Conflict/Risk engine will consume. **This phase deliberately does NOT create Conflict records, assign severity, or interpret the overlap** — CONTEXT.md puts all of that in Phase 04.2 (`INTG-03`). Detection is a callable service method plus a read endpoint; nothing more.
Output: service method, response schema, endpoint, and a deterministic two-project integration test.

**Design decision this plan implements (resolves RESEARCH.md Open Question #3):**
Overlap detection is a **service method + read endpoint**, never a database trigger. The repo has zero triggers in `supabase/migrations/`, and a write-time trigger would push interpretation logic into SQL — which belongs in Phase 04.2's service layer. The endpoint exists so GEOF-04 is verifiable over HTTP; Phase 04.2 decides when to call the detection (sync on write vs. async job).
</objective>

```python
    async def detect_boundary_overlaps(self, project_id: str) -> list[dict[str, Any]]:
        """Overlap interno entre projetos do proprio Sinarca (GEOF-04).

        ST_Intersects e o pre-filtro barato: em coluna com indice GiST
        (project_boundaries_active_boundary_gix) ele usa o bounding box do
        indice em vez de calcular geometria par a par. ST_Intersection +
        ST_Area(::geography) so rodam para quem realmente cruza.

        ST_Area precisa do cast ::geography: em geometry(Polygon, 4326) o
        resultado sai em graus quadrados, nao em metros quadrados.

        Esta fase NAO interpreta o overlap: nao cria Conflict, nao atribui
        severidade e nao bloqueia nada. Isso e Phase 04.2 (INTG-03).
        """
        project = await self._get_project_model(project_id)
        rows = (
            await self.session.execute(
                text(
                    """
                    select
                      other_p.id::text as related_project_id,
                      other_p.friendly_id as related_project_friendly_id,
                      other_p.name as related_project_name,
                      ST_Area(ST_Intersection(mine.active_boundary, other.active_boundary)::geography) / 10000.0
                        as overlap_area_ha,
                      (
                        ST_Area(ST_Intersection(mine.active_boundary, other.active_boundary)::geography)
                        / nullif(ST_Area(mine.active_boundary::geography), 0)
                      ) * 100 as overlap_percentage,
                      (
                        ST_Area(ST_Intersection(mine.active_boundary, other.active_boundary)::geography)
                        / nullif(ST_Area(other.active_boundary::geography), 0)
                      ) * 100 as overlap_percentage_of_related
                    from project_boundaries mine
                    join project_boundaries other
                      on other.project_id != mine.project_id
                      and ST_Intersects(mine.active_boundary, other.active_boundary)
                    join projects other_p on other_p.id = other.project_id
                    where mine.project_id = :project_id
                    order by overlap_percentage desc
                    """
                ),
                {"project_id": str(project.id)},
            )
        ).mappings().all()

        return [
            {
                "relatedProjectId": row["related_project_id"],
                "relatedProjectFriendlyId": row["related_project_friendly_id"],
                "relatedProjectName": row["related_project_name"],
                "overlapAreaHa": round(float(row["overlap_area_ha"] or 0.0), 4),
                "overlapPercentage": round(float(row["overlap_percentage"] or 0.0), 4),
                "overlapPercentageOfRelated": round(float(row["overlap_percentage_of_related"] or 0.0), 4),
            }
            for row in rows
        ]
```

Do not add any Conflict/severity/risk logic, any threshold constant, or any write of any kind in this method — it is read-only by design.

```python
def rectangle_tags(prefix: str, base_lat: float, base_lng: float, span: float = 0.02) -> list[dict[str, object]]:
    """Retangulo axis-aligned: A(NO) B(NE) C(SE) D(SO). Coordenadas em (lat, lng)."""
    points = [
        ("A", base_lat, base_lng),
        ("B", base_lat, base_lng + span),
        ("C", base_lat - span, base_lng + span),
        ("D", base_lat - span, base_lng),
    ]
    return [
        {
            "tag_uid": f"{prefix}-{index}",
            "cmac": f"cmac-{prefix}-{index}",
            "latitude": latitude,
            "longitude": longitude,
            "vertex_label": label,
        }
        for index, (label, latitude, longitude) in enumerate(points, start=1)
    ]
```

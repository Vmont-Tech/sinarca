<objective>
Serve the persisted geometry to the frontend. Add a `boundary_item` serializer that returns the stored polygon as GeoJSON via `ST_AsGeoJSON`, wire it into both payloads that feed `ProjectGeofencePreview` (the public dossier and the certifier review), and apply the repo's existing response-minimization pattern so the public payload does not carry internal validation metadata.

Purpose: GEOF-05, backend half. Today `ProjectGeofencePreview` is fed raw `tags` and recomputes the polygon client-side at every render. It cannot stop doing that until the API actually ships the persisted polygon — this plan ships it. The frontend switch is plan 04.1-05.
Output: serializer + two payload fields + integration tests asserting GeoJSON shape and coordinate order.

**Minimization decision this plan implements (consistent with D-20/D-22 in STATE.md):**
Two serializers, mirroring the existing `certification_item`/`public_certification_item` and `document_item`/`public_document_item` split:
- `boundary_item(...)` — full internal view: geometry + area + `declaredSource` + `areaDivergencePct` + `areaDivergenceFlagged` + `activeTier`. Used by the certifier review.
- `public_boundary_item(...)` — public view: geometry + `declaredAreaHa` + `declaredVertexCount` + `activeTier` only. Drops `declaredSource` and both area-divergence fields, which are internal validation telemetry. Used by the public dossier.
</objective>

```python
    async def boundary_item(self, project_id: str) -> dict[str, Any] | None:
        """Geometria persistida serializada como GeoJSON (GEOF-05).

        ST_AsGeoJSON emite coordenadas [longitude, latitude] — a convencao do
        GeoJSON/PostGIS, INVERSA da convencao (latitude, longitude) usada no
        resto do repo e pelo Leaflet. Quem consome no frontend precisa inverter.

        Visao interna completa. Para o dossie publico use public_boundary_item()
        por cima deste retorno.
        """
        row = (
            await self.session.execute(
                text(
                    """
                    select
                      ST_AsGeoJSON(declared_boundary) as declared,
                      ST_AsGeoJSON(active_boundary) as active,
                      ST_AsGeoJSON(field_verified_boundary) as field_verified,
                      ST_AsGeoJSON(certified_boundary) as certified,
                      declared_area_ha,
                      declared_vertex_count,
                      declared_source,
                      declared_area_divergence_pct,
                      declared_area_divergence_flagged,
                      active_boundary_tier
                    from project_boundaries
                    where project_id = :project_id
                    """
                ),
                {"project_id": str(project_id)},
            )
        ).mappings().one_or_none()

        if row is None:
            return None

        return {
            "declared": json.loads(row["declared"]) if row["declared"] else None,
            "active": json.loads(row["active"]) if row["active"] else None,
            "fieldVerified": json.loads(row["field_verified"]) if row["field_verified"] else None,
            "certified": json.loads(row["certified"]) if row["certified"] else None,
            "declaredAreaHa": float(row["declared_area_ha"]) if row["declared_area_ha"] is not None else None,
            "declaredVertexCount": int(row["declared_vertex_count"]) if row["declared_vertex_count"] is not None else None,
            "declaredSource": row["declared_source"],
            "areaDivergencePct": (
                float(row["declared_area_divergence_pct"]) if row["declared_area_divergence_pct"] is not None else None
            ),
            "areaDivergenceFlagged": bool(row["declared_area_divergence_flagged"]),
            "activeTier": row["active_boundary_tier"],
        }
```

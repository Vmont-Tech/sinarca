**shadcn gate rationale (no question asked):** Same rationale as `04-UI-SPEC.md` — no `components.json` exists in this repo and Phase 4 already formalized the hand-rolled Tailwind system as canonical. This contract continues Phase 4's decision.

**Three pre-existing surfaces this phase touches — read before implementing.** Unlike Phase 4 (one cohesive internal workbench), Phase 5 extends **three already-shipped, visually distinct surfaces**, each with its own established convention. Discovering and preserving each one (rather than inventing a fourth) is the primary job of this contract:

This is precisely the surface SATM-07 requires retiring as a data source — **the dark visual shell stays, the fake data and fake map get replaced.** Do not build a new page; evolve this one, and make it project-scoped (route param) instead of hardcoded.

## Spacing Scale

Declared values (must be multiples of 4) — identical scale across all three surfaces, continuing Phase 4's contract without change:

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon-to-label gaps (`gap-1`), tight inline padding |
| sm | 8px | Compact spacing between badge/chip and adjacent text (`gap-2`), layer-toggle button group padding (`p-1`) |
| md | 16px | Default field/element spacing (`p-4`, `gap-4`), metric-card internal padding on Surface B (`p-6`≈lg, see below) |
| lg | 24px | Card internal padding (`p-6`), section gaps (`gap-6`, `space-y-6`) — the default card padding on **both** Surface A and Surface B |
| xl | 32px | Public dossier tile-grid card padding (`p-8`, Surface C), major card-to-card spacing (`space-y-8`) |
| 2xl | 48px | Not newly needed this phase |
| 3xl | 64px | Not newly needed this phase |

Exceptions (carried over, not introduced by this phase):
- Decision/action buttons (Aprovar / Bloquear / Recalcular on Surface A; the new **Confirmar anomalia / Descartar anomalia** on Surface B) use `px-4 py-3` (16px/12px) — a ~44px tap target, matches WCAG 2.5.5, must be preserved.
- Eyebrow/meta labels use `text-[10px]`/`text-[11px]` non-4px-adjacent sizing — pre-existing, scoped to labels only, never layout spacing. Surface B uses this pervasively (`text-[10px] uppercase font-bold tracking-widest`) for every stat label, map badge, and corner overlay — continue that density exactly for the new layer-toggle group and before/after slider corner labels.
- The map layer-toggle button group (new, extends `MonitoringNDVI.tsx:151-170`'s existing 3-button pattern to 7 layers) uses the same `p-2`/`gap-2` compact stacked-button spacing already established there — do not widen it to accommodate more buttons; wrap to a second row instead if needed at narrow viewports.

## Typography

| Role | Size | Weight | Line Height |
|------|------|--------|-------------|
| Body | 14px (`text-sm`) | 400 regular | 1.5 |
| Label / eyebrow | 10–12px (`text-[10px]`/`text-xs`, uppercase, `tracking-widest`/`tracking-[0.2em]`) | 700 bold | 1.2 |
| Heading | 20–24px (`text-xl`/`text-2xl`) | 700 bold | 1.2 |
| Display | 30–36px (`text-3xl`/`text-4xl`) | 700 (Surface B, `font-serif`) or 900 (Surfaces A/C, `font-black`) | 1.1–1.2 |

Declared weights: **400 (regular, body copy)** and **700 (bold, labels/headings/buttons)** — exactly 2, per contract, plus one documented pre-existing per-surface exception below.

**Pre-existing exceptions carried over (not introduced by this phase):**
- Surfaces A and C already use `font-black` (900) for their page/section `h1`/`h2` (`AuditorReview.tsx:353`, `MrcaDetails.tsx:191/237`) — continue this weight for any new `h1`/`h2` added to those two surfaces (e.g. no new heading level should be invented at 700 to "fix" the rule; the rule constrains new choices, not established headings, exactly as Phase 4 documented).
- Surface B already uses `font-serif font-bold` (700, **not** 900) for its `h1` (`MonitoringNDVI.tsx:106`) and its metric-card values (`font-serif font-bold text-2xl`, line 261). This phase's new headings on Surface B (timeline chart title, anomaly list title, before/after slider title) must match this **700**, not upgrade to 900 — Surface B never uses `font-black` today and this phase must not introduce it there.
- `text-[10px]`/`text-[11px]` micro-labels remain scoped exclusively to eyebrow/meta text (chip labels, layer-toggle button labels, corner map overlays, timestamps) — never body copy or primary reading content, on any of the three surfaces.

## Color

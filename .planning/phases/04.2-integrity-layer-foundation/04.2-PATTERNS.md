Key conventions to replicate for `Claim`/`Evidence`/`Conflict`/`ProjectRiskAssessment`/`RiskSignal`:
- `status`/`type`/`severity`/`source_type`/`validation_method` columns are **plain `String`**, never `Enum(...)` — the DB-level constraint lives in the migration's `check (...)`, not in `models.py`. (Confirmed repo-wide: `Enum(...)` is only used for the 6 original Postgres `ENUM` types — `UserRoleEnum`, `ProjectStatusEnum`, `CreditStatusEnum`, `LedgerEntryTypeEnum`, `ChainEventTypeEnum`, `ExternalChainEnum` — all declared with `create_type=False` at `models.py:16-77`. New tables never re-enter this pattern.)
- `id: Mapped[uuid.UUID] = uuid_pk()` helper (`models.py:80-81`) for every PK.
- `created_at: Mapped[datetime] = created_at_column()` helper (`models.py:84-85`).
- `metadata_: Mapped[dict] = mapped_column("metadata", JSONB, ...)` — Python attribute is `metadata_` (avoids SQLAlchemy's reserved `metadata`), DB column is `"metadata"`.
- FK-nullable pattern for "may not always apply" relations, e.g. `Evidence.claim_id` (D-22: nullable safety valve) mirrors `CertificationPendency.certification_id: Mapped[uuid.UUID | None]`.

**Project table additions** — add `integrity_status`/`risk_score` as sibling columns to existing `Project` class fields (`models.py:143-192`), same `String`/`Numeric` style already used for `status`/`carbon_stock`:
```python
    status: Mapped[str] = mapped_column(ProjectStatusEnum, nullable=False, server_default=text("'REGISTERED'"))
    # existing pattern to mirror for the NEW plain-string column:
    # integrity_status: Mapped[str] = mapped_column(String, nullable=False, server_default=text("'DECLARED'"))
    # risk_score: Mapped[int | None] = mapped_column() -- or Numeric, informative only per D-05
```

**RLS / backend-only pattern** (`202608150001_certification_workbench.sql:58-65`, and the geometry-adjacent variant with GiST index at `202608150003_project_boundaries.sql:46-58`):
```sql
alter table certification_pendencies enable row level security;
alter table treasury_authorizations enable row level security;

revoke insert, update, delete on certification_pendencies, treasury_authorizations

-- Sem politicas de select: pendencias e autorizacoes sao dados operacionais

```
Apply the same `enable row level security` + `revoke ... from anon, authenticated` + **no** select policy to `claims`, `evidence`, `conflicts` (per RESEARCH.md Pattern 3 / Security Domain — Conflict rows reveal cross-org project proximity, same sensitivity class as `project_boundaries`).

**Idempotent-migration guard** for any constraint needing `IF NOT EXISTS`-style safety (`202608160001_scope_document_hash_uniqueness_by_type.sql:8-19`):
```sql
do $$
begin
  if not exists (
    select 1 from pg_constraint
    where conname = 'documents_project_type_sha256_key'
      and conrelid = 'documents'::regclass
  ) then
    alter table documents
      add constraint documents_project_type_sha256_key unique (project_id, document_type, sha256_hash);
  end if;
end $$;
```

**`Evidence.hash` FK reuse of `documents.sha256_hash`** — model it as a plain `text not null` column populated from `documents.sha256_hash` at write time (D-07), not a new hash computation; add `document_id uuid references documents(id)` alongside it (nullable per D-22 for the `RIGHT_TO_OPERATE` fallback linkage).

```python
async def _ensure_locked_credit(self, project: Project, amount: Decimal) -> EnvironmentalCredit:
    result = await self.session.execute(
        select(EnvironmentalCredit).where(
            EnvironmentalCredit.project_id == project.id,
            EnvironmentalCredit.vintage == project.vintage,
        )
    )
    credit = result.scalar_one_or_none()
    if credit is None:
        credit = EnvironmentalCredit(...)

    else:
        credit.quantity_total = amount
        credit.status = "LOCKED"
    await self.session.flush()
    return credit
```

```python
async def create_audit_event(
    session: AsyncSession,
    *,
    action: str,
    entity_type: str,
    entity_id: Any | None = None,
    actor_profile_id: Any | None = None,
    actor_role: str | None = None,
    before_data: dict[str, Any] | None = None,
    after_data: dict[str, Any] | None = None,
    metadata: dict[str, Any] | None = None,
) -> AuditEvent:
    event = AuditEvent(
        action=action,
        entity_type=entity_type,

        actor_profile_id=actor_profile_id,
        actor_role=actor_role,
        before_data=before_data,
        after_data=after_data,
        metadata_=metadata or {},
    )
    session.add(event)
    await session.flush()
    return event
```

### Org-scoped access guard
**Source:** `backend_app/modules/projects/service.py:1426-1445` (`_assert_project_edit_permission`)
**Apply to:** every new `GET /projects/{id}/claims|evidence|conflicts|integrity` route in `integrity/routes.py` — same pattern already used for `/boundary-overlaps` and `/pendencies`.
```python
async def _assert_project_edit_permission(
    self,
    project: Project,
    *,
    actor_id: str | None,
    actor_role: str | None,
) -> None:
    if actor_role == "admin":
        return
    profile = await self._actor_profile(actor_id)
    organization_id = profile.organization_id
    allowed = False
    if organization_id is not None and actor_role == "producer":
        allowed = organization_id in {project.producer_organization_id, project.developer_organization_id}
    elif organization_id is not None and actor_role == "certifier":
        allowed = organization_id == project.certifier_organization_id

    if not allowed:
        raise HTTPException(status_code=status.HTTP_403_FORBIDDEN, detail="Seu perfil não pode editar este projeto")
```
